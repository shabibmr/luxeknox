Member dossier

Trainer and admin view of one member. /trainer/members/:id

6:52
  • One hero: membership days left in Fraunces, with the plan and end date tucked under it. Balance and visits are the under-count, in two equal columns.
  • Nia sits 8dp over the hero's top-left edge. She breathes on a 4s cycle and holds still when motion is off.
  • For trainers, starting a session is the only filled button. Admins get sell, renew, and change instead.
  • The knee note from Notes moves above the fold, because it changes what a trainer programmes.
  • Edit turns the contact list into fields in place. Renew uses a bottom sheet instead of an alert dialog.

Workout plan builder

Editing a member's draft plan. /trainer/plans/workout/:id/edit

6:52
  • Days become tabs instead of one long scroll. The selected day's set count is the hero, with estimated time under it.
  • Each exercise collapses to one line: sets × reps at load, then rest. Tap it to edit with steppers and rest chips.
  • Plan details fold into a summary row. Only the title stays open, because it's required.
  • Labels stay "Day N". The API has no day name, so the mock doesn't invent one.
  • Try Save with an empty title, Back with unsaved changes, Remove then Undo, and "+ Day" then closing the picker.
